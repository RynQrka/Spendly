# Spendly

Spendly is an AI-powered personal finance assistant designed to manage personal spending, subscriptions, and finances through natural language.

## Features

- Conversational expense logging via Telegram
- Natural language queries for spending insights and monthly summaries
- Recurring subscription management (rent, utilities, services)
- AI-based intent classification for:
  - Expense logging
  - Queries
  - Corrections
  - Exports
  - Insights
  - Acknowledgements
- Spending insights and anomaly detection
- Report export functionality
- Tone-aware responses that adapt to user communication style
- Local SQLite storage for:
  - Expenses
  - Users
  - Recurring plans
  - Conversation history
- Web and bot interfaces for both chat and dashboard-style interactions

## Behavior

Spendly processes incoming messages, classifies user intent, and responds conversationally using AI. It maintains context across interactions, tracks expense history, and keeps recurring subscriptions synchronized to simplify regular financial management.
